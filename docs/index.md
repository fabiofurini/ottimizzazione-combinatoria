# Ottimizzazione combinatoria

Le dispense di ottimizzazione combinatoria: zaino, bin packing, colorazione, commesso viaggiatore, scheduling su macchine parallele e lot sizing, risolti in tutti i modi: formulazioni e loro proprietà, programmazione dinamica, algoritmi euristici e di approssimazione, algoritmi specializzati.

## Parti del corso

- Problemi di ottimizzazione combinatoria
- Formulazioni e loro proprietà
- Programmazione dinamica
- Algoritmi euristici
- Algoritmi di approssimazione
- Algoritmi specializzati
