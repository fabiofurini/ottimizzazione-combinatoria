# Colorazione: il branch-and-bound DSATUR

L'albero delle colorazioni parziali nodo per nodo: vertice più saturo, un figlio per colore ammissibile più un colore nuovo, potatura con q ≥ UB. ◀ ▶ un passo alla volta, «Esegui» per vederli tutti (velocità a scelta); il menu «Istanza» e «Modifica…» cambiano l'istanza.
